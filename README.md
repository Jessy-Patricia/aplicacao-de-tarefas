# 🚀 Task Manager Pro - React

Uma aplicação avançada de gerenciamento de tarefas focada em **UX (User Experience)** e **Clean Code**. Este projeto foi desenvolvido para demonstrar o domínio de conceitos modernos de React.

## Tecnologias e Funcionalidades

- **React (Hooks & Context API):** Gerenciamento de estado global para sincronização entre páginas.
- **Custom Hooks:** Implementação de `useLocalStorage` para persistência de dados.
- **Dark Mode:** Sistema de temas com Context API e Variáveis CSS.
- **Framer Motion:** Animações fluidas de entrada, saída e transição de estados.
- **React Router:** Navegação SPA (Single Page Application).
- **Responsividade:** Interface adaptável para dispositivos móveis (Mobile-First).

## 💡 O que eu aprendi
Neste projeto, foquei em separar as responsabilidades da aplicação. Em vez de deixar toda a lógica no Contexto, criei hooks customizados para a persistência, o que torna o código mais legível e fácil de manter. Também explorei o uso de `AnimatePresence` para garantir que a interface não fosse estática ao remover os itens da lista.
